# AI collaboration records

This directory contains redacted public selections from OpenAI Codex and Claude collaboration records. The selections include prompts, model responses and examples of correction. Source identifiers and available counts are recorded in manifest.json.

- selected_records.md and selected_records.jsonl: selected Codex material.
- claude_selected_records.md: selected Claude material.

Selections are not complete account histories. Source-declared message counts can differ from explicit exported message headings; the manifest preserves that distinction. Codex selections include English renderings, while Claude selections include original-text excerpts. Chinese is retained only in this directory.

Personal identifiers, contact details, affiliation terms and local account paths are redacted. Some historical example commands therefore contain redaction markers and are not executable reproduction instructions. Binary attachments and raw account exports are excluded.

Historical assistant statements can be incorrect or superseded. Current RTL, test outputs and implementation reports determine the supported technical claims.
